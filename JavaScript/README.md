# JavaScript Notes:


## 1. Variables and Scope
- var is function scoped
- let and const are block scoped
- Variables inside blocks are not accessible outside

Example:
A variable declared with let inside { } cannot be accessed outside the block.

---

## 2. Hoisting
- var is hoisted and initialized as undefined
- let and const are hoisted but not initialized (Temporal Dead Zone)

---

## 3. Functions
- Function declarations are hoisted
- Arrow functions are not hoisted
- Both can be used to perform calculations

---

## 4. Objects and Arrays
- Objects store key-value pairs
- Arrays store ordered lists of values

---

## 5. Destructuring
- Extract values from objects and arrays easily

---

## 6. Spread Operator
- Used to copy and expand arrays/objects

---

## 7. Immutability
- Original data is never modified
- New copies are created instead
